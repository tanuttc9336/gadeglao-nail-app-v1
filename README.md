# 🌸 Gadeglao Nail App — แอปฝั่งลูกค้า เกศเกล้า บึงสามพัน

เว็บแอปสำหรับ**ลูกค้าและคนทั่วไป** ของร้านเกศเกล้า บึงสามพัน (เล็บ · สปามือเท้า · ผม · ขนตา)
แยกจากระบบหลังร้าน (GadeGlao OS) — หน้านี้เป็น static ล้วน ไม่แตะฐานข้อมูล ปลอดภัยแชร์สาธารณะได้

**Live:** https://gadeglao.netlify.app/shop.html

## โครงสร้าง

| ไฟล์ | คืออะไร | สถานะ |
|---|---|---|
| `index.html` | หน้า explore สาธารณะ — ลองสีเล็บ interactive (พาเลตสีมงคลเปลี่ยนตามวันจริง) · เลือกบริการตาม 4 ความรู้สึก · เมนู+ราคาจริง ~30 รายการ · มาตรฐานร้าน · วิธีมาร้าน · CTA LINE | ✅ ใช้จริง |
| `mockup-member-card.html` | บัตรสมาชิกส่วนตัว (ทักชื่อ · แสตมป์ 8 ครั้ง · ถึงรอบสวย · สิ่งที่เราจำได้) | 🎨 mockup |
| `mockup-member-interactive.html` | ห้องลองสีแบบ personalize (โทนที่พี่ชอบจากแท็กรายคน) | 🎨 mockup |

## หลักออกแบบ

1. เปิดมาเจอสิ่งที่เป็นของลูกค้าก่อน (ชื่อ/สีของวัน) — ไม่ใช่โฆษณา
2. Zero navigation: หน้าเดียวเลื่อนลง · ปุ่มหลักปุ่มเดียว (LINE)
3. ราคาชัดทุกรายการ — ไม่มี "ทักแชทถามราคา"
4. ตัวหนังสือ ≥16px แตะ ≥44px โหลดไวใน LINE webview · ไฟล์เดียวจบ ไม่มี build step
5. ภาษาพี่สาว + อารมณ์ขันจริงใจ ("ต้องขับเลยหนึ่งครั้ง ถึงจะมาถูก")

## Deploy

ลากไฟล์ทั้ง repo ขึ้น Netlify (โปรเจกต์ `gadeglao`) — `index.html` ของ repo นี้ deploy เป็น `shop.html` บนเว็บร้าน

## กติกาแบรนด์ที่โค้ดทุกบรรทัดต้องเคารพ

ราคาลงท้าย 0 · ไม่มีคำเคลมผิวขาว/ใส · ไม่อ้าง อย. · สายมูพูดเฉพาะฝั่งบวก "ตามความเชื่อ" · "บึงสามพัน" อยู่คู่ชื่อร้านเสมอ · ไม่ลดราคาตัวบริการ (เพิ่มคุณค่ารอบๆ แทน)

## Workflow ร่วมกับโปรเจคหลัก (GadeGlao OS)

- repo นี้ = **source of truth ของหน้าฝั่งลูกค้า** (`index.html`)
- ทุก deploy: `index.html` ถูก sync เป็น `shop.html` ในเว็บร้าน (สคริปต์ `build-site.sh` ใน session)
- เชื่อมสองทิศ: แอปร้านมีการ์ด "🌐 หน้าเว็บลูกค้า" (QR พิมพ์ติดหน้าร้าน) · หน้าลูกค้ามีลิงก์เล็ก "สำหรับทีมงาน" ที่ footer
